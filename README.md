# Listix — Smart, Minimalist Task Workspace

A modern, responsive productivity web application built with vanilla HTML5, CSS3, and modern JavaScript (ES Modules). Designed with a distraction-free pastel aesthetic, Microsoft-inspired split landing layout, and a Gemini/ChatGPT-style workspace.

## 🚀 Live Demo
[View Live Application](https://hafsanaeem2712.github.io/todoApp/)

## ✨ Key Features
- **Local Persistence:** Retains tasks across sessions using browser `localStorage`.
- **Inline Task Editing:** Double-click or click Edit to modify tasks in-place.
- **Priority Management:** Assign Low, Medium, or High priority flags.
- **Real-time Live Search:** Filter tasks dynamically as you type.
- **Theme Support:** Dark and Light mode toggle with saved user preference.
- **Productivity Progress & Celebration:** Live completion progress bar with confetti animation.
- **Responsive Layout:** Adaptive sidebar drawer for mobile and desktop screens.

## 🛠️ Built With
- Semantic HTML5
- Custom CSS3 (CSS Variables, Flexbox, Grid, Ambient Gradients)
- Vanilla JavaScript (ES6+ Modules)
- Canvas Confetti library
